### 为什么是"一次建满"而不是分批

1. **策略是月频系统性组合，回测假设"信号日全额建仓"。** 分批等于加入一个回测里
   不存在的择时自由度 —— 前三个模型正是死在多余自由度上（`docs/12` §6.2）。
2. **流动性完全不是约束**：最大一笔 DBC 约 24.4 万美元，而它日均成交额约 1,900 万美元，
   占比 **1.3%**；其余各笔占比更低。
3. **唯一该分批的两种情形都不成立**：单笔占日成交量数个百分点（不成立）、
   资金买不起一手（美股 1 股起，不成立）。
4. 入场当天盘面偏弱（EEM −2.9%、QQQ −1.3%、SLV −2.4%），使多数标的的成交价
   低于信号日收盘 —— 但这**不是**理由，只是运气。理由是没有理由分批。

### 与回测的一处已知偏差

首次建仓用的是 **2026-09-11（周五）收盘**的信号，在 **09-14（周一）** 盘中成交，
即**存在 1 个交易日的实施滞后**。回测假设"决策日收盘价成交"。
这是所有实盘都会有的摩擦，量级约 ±0.6%（组合日波动），记录在案。
下一轮起按纪律在月末收盘后算信号、次日盘中下单，**滞后固定为 1 个交易日**。

## 2. 每一轮的固定操作清单（3 步）

**第 1 步 · 更新数据**（约 1 分钟）
双击 `launcher\34-多资产·下载ETF数据.bat`
→ 增量下载 15 只 ETF + 现金腿的最新日线（断点续传，不会重复下载）。

**第 2 步 · 看新目标权重**
双击 `launcher\36-多资产·生成调仓信号.bat`（**注意**：默认配置是加杠杆版，
需要现金版时用下面的命令）
```powershell
python stock_market_GLOBAL\scripts\gl_build_signal.py --cfg stock_market_GLOBAL\config\gtaa_cash_only.json
```

**第 3 步 · 下差额单**
```powershell
# 先演练（默认，不发任何指令）
python stock_market_GLOBAL\scripts\gl_place_orders.py

# 核对无误后再真下单
python stock_market_GLOBAL\scripts\gl_place_orders.py --execute
```

### ⚠️ 第 3 步有两条纪律

1. **必须先看演练输出**：确认账户闸门显示 `env=SIMULATE`、
   `账户指纹 US.UNH ... ✅ 匹配`、`可投入现金` 与 `合计名义` 都在合理范围。
   **任何一项显示 ❌ 或异常 → 立即停止，不要加 `--execute`。**
2. **`gl_place_orders.py` 目前只支持"买入"**（`place_cash_only_batch` 只发 BUY）。
   因此**调仓时如果某个标的需要减仓或清仓，必须先手工卖出**（在富途 App 里操作，
   或在确认 `safe_trade` 支持卖出后扩展脚本），**然后**再跑 `--execute` 买缺的部分。
   否则会出现"想减仓却只能加仓"的错配。

> 📌 **待补的工程项**：给 `safe_trade` 增加**卖出**通道（同样带三道闸门，
> 但金额校验换成"不得超过持仓数量"）。在它完成之前，**本策略的调仓只能靠人工卖出**。
> 这是当前最重要的一个缺口，已列入下一轮待办。

## 4. 监控什么、什么时候该找人

### 4.1 每月例行（5 分钟）

| 指标 | 正常范围 | 越界怎么办 |
|---|---|---|
| 实际 gross | ≤ 100%（现金 ≥ 0） | 现金变负 = **已经用了融资 → 立即减仓** |
| 组合回撤 | < 15% | 见 §4.2 |
| 持仓只数 | 6~15 只 | 只数过少说明趋势集中，属正常但需记录 |

### 4.2 异常阈值（"历史没发生过"的界线）

本策略现金版在 2003-2026 的**最大回撤是 14.97%**。因此：

| 组合回撤 | 含义 | 动作 |
|---|---|---|
| < 15% | **历史正常范围** | 什么都不做（这是策略的正常呼吸） |
| 15% ~ 20% | 与历史极值同级 | 记录，不干预 |
| **20% ~ 25%** | **超出历史极值** | 人工复核：数据源是否正常？下单是否错价？ |
| **> 25%** | 历史没发生过 | 停手，重新评估策略是否失效（见 §4.3） |

> ⚠️ **回撤调速器（尾保档）在现金版下 = 目标波动 15% × 2.5 = 37.5% 才触发。
> 也就是说：它的设计意图是"历史没发生过的尾部"，而不是日常风控。
> 日常风控靠的是逐资产趋势门 + 波动率目标这两层，它们每个调仓日都在工作。**

### 4.3 判断"策略是不是失效了"（而不是看短期盈亏）

**不要用赚亏判断**。用这三条，任一条持续成立才算失效信号：

1. **趋势门失效**：连续 6 个月，"持有中的标的"在下一月的表现**差于**"因趋势为负而被
   剔除的标的"。这说明时序动量在这个市场环境里反向。
2. **分散失效**：组合日波动持续高于 15%（目标 10.4% 预测波动），
   且持仓之间的相关性明显上升 —— 说明 8 个资产类别在往一个方向走。
3. **执行偏差**：实际净值与"用同一信号纸面复现的净值"月度偏差持续 > 0.5%
   （说明成本、滑点或下单流程出了问题，而不是策略问题）。

第 3 条最值得每月做：**用同一个信号跑一遍纸面净值，与模拟盘实际净值对比** —
这是唯一能区分"策略亏了"和"执行错了"的办法。
